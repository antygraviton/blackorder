Put custom 3D models in glTF binary format (.glb) here.

soldier.glb   - enemy (about 1.8 m tall, feet at the origin, face looking along the -Z axis).
                If it has an AnimationPlayer with animations named "idle" and "walk", they are played.
hk416.glb, ak.glb, mp5.glb, shotgun.glb, svd.glb, glock.glb, revolver.glb, knife.glb, m67.glb
                - weapon held by the player (barrel pointing along the -Z axis).

When a file exists it replaces the model built from boxes. When it is missing the game keeps working.

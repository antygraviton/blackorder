# Glossary: Czech working names → English names

| Czech (original) | English (now) | Where it appeared |
|---|---|---|
| Černý řád / Cerny rad | **Black Order** | game title, faction (the secret organization); Unreal module id `CernyRad` is kept |
| Ocelová pěst | **Steel Fist** | campaign 2 and its third mission |
| Zmizelá vesnice | The Vanished Village | campaign 1, mission 1 |
| Průnik do základny | Base Infiltration | campaign 1, mission 2 (draft 1.1 retitles it "Silent Infiltration") |
| Město pod palbou | City Under Fire | campaign 1, mission 3 |
| Konvoj | Convoy | campaign 2, mission 1 |
| Letiště | Airfield | campaign 2, mission 2 |
| Řád | the Order | short name of the faction |
| Weapoints | Weapoints (WP) | currency; unchanged |
| Medaile | medals | premium currency |
| Hrát / Nastavení / Ukončit | Play / Settings / Quit | menu |
| Přestřelka proti botům | Team Match vs Bots | mode |
| Luk | Bow | weapon |
| Kuše, Mačeta, Kladivo | Crossbow, Machete, Hammer | weapons |
| Dýmovnice | Smoke grenade | weapon |
| Spojenci Alfa a Bravo | allies Alpha and Bravo | AI allies |
| Spojka / Velitelství | Contact / HQ | radio voices in 1.1 drafts |

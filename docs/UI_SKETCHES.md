# Original UI sketches

The project began from hand-drawn sketches (not stored in this repository). Their structure, as transcribed during the first session, defines the menus:

| Screen | Contents |
|---|---|
| **Main menu** | Play, Multiplayer, Settings, Store, Quit; player box with name, level and statistics |
| **Play** | list of campaign missions; further modes: Training, Survival, Zombie Arena (initially shown as "coming later") |
| **Multiplayer** | party code, team size selector 1v1 … 5v5, party member list with free slots, "Join with code" and "Create party" |
| **Settings** | tabs Audio, Controls, Game |
| **Store** | categories Primary, Secondary, Melee, Grenade; weapon list with buy/equip |

Implementation status: all five screens exist. The Play screen was reorganized into tabs (Campaign / Quick Games). The Multiplayer team-size selector (1v1 … 5v5) was replaced by the actual rules
(co-op for up to 3, Team Match vs bots); a true 1v1 … 5v5 mode is on the roadmap.
